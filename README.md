# TravelGo — One Panel Frontend

TravelGo is a frontend-only travel and tourism portfolio project.

## One deployment

The customer website and admin panel are inside the same React application.

- Website: `/`
- Admin panel: `/admin`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify

Build command:

```text
npm run build
```

Publish directory:

```text
dist
```

No Supabase, backend, database, or `.env` is required. Demo data uses localStorage.
